# kiln-issue-filter — issue 页按领域 / 状态 / 标签筛

## 问题

issue 页只有一种顺序（按最近动作倒序）。仓库一多就难找：

- kiln 自己带 `domain`，`~/kiln` 里是 `design 29 / cli 28`——想只看一个领域，现在只能眼睛扫；
- trailer 里还有 `tags:`，本仓 4 条 issue 带标签（`focus ×3`、`flow ×2`…），想按标签收窄没入口；
- 快照本来就带 `done`，但只有行尾一个 `done` 小标签，没法"只看没做完的"。

数据是现成的：`kiln graph --json` 的节点已经有 `domain / tags / done / action / title`，
宿主侧 `flow.js` 也已经原样透传（`domain`、`tags`、`done` 都在快照里），不需要动数据层。

## 目标

issue 页（无焦点时的列表）加一行筛选：

- 三个维度：**领域 / 状态 / 标签**；
- 同组多选是 **OR**（领域 A 或 B），组间是 **AND**（领域 A 且标签 x）；
- 没有可选项的组不出现（只有一个领域就不给"按领域筛"，没有标签就不给标签组）；
- 筛选只作用于列表；聚焦读的是结构，不掺筛选。

## 边界

- **客户端过滤**：不调 `kiln list --domain/--tag`，也不给宿主路由加参数——
  视图要的是"同一份快照内即时切换"，而且 `list` 只有 issue 名，没有关系与动作。
- 不做全文搜索（这一版只做属性筛选，搜索另议）。
- 不改时间线页、不改图；筛选条只在 issue 页出现。
- 筛选状态按仓库记在内存里（与页签、焦点同一套），刷新页面清空。

## 验收

- 页栏右侧出现「筛选」按钮；展开后在页栏下方出现一行 chips，不随内容滚动。
- 选中后按钮显示计数（`筛选 2`），计数区变成 `命中 / 总数 issue`。
- 命中为空时文案是「没有符合筛选条件的 issue。」，不是「这个仓库还没有 issue。」。
- 筛选状态切页回来还在；「清除」一键回到无筛选。
- 纯函数（facets / 过滤）可单测：分组只在有得选时产出、同组 OR、组间 AND。

## 收集：数据长什么样

`kiln graph --json` 的节点字段（本仓实测）：

```json
{ "id": "kiln-dsh-integration", "domain": "integration", "action": "apply",
  "done": true, "title": "…", "tags": ["plugin", "flow"] }
```

`kiln path <id> --json` 只给 `issue / action / done / actions / relations`，
每个 action 有 `ordinal / action / id / date / title` —— **动作级没有 tags**，
所以标签只能按"这条 issue 上出现过的全部标签"来筛（快照里的 `tags` 就是各动作 trailer 的并集）。

两个仓的分布（决定"哪些维度值得做"）：

| 仓库 | issue | 领域 | 带标签的 issue | 不同标签 | 已完成 |
| --- | --- | --- | --- | --- | --- |
| dsh-kiln | 15 | `integration 15` | 4 / 15 | 12 | 15 / 15 |
| `~/kiln` | 58 | `design 29 / cli 28` | **0 / 58** | 0 | 50 / 58 |

两条结论：

1. **领域**是真实维度（2–3 个值，覆盖 100%）→ 主维度；
2. **标签**用得很少（一个大仓里 0 条、本仓 4 条）→ 不能当主入口，但完全没有也不行
   （想按 `focus` 收窄时它正好是唯一手段）→ **有就出现、没有就不出现**；
3. **状态**只有两值且常常一边倒（本仓 15/15 全是已完成）→ 同理，只有一个值时整组隐藏。

`kiln list` 自带 `--domain=` / `--tag=` / `--action=`，但我们不用它：
一是它每次要起一个子进程、换一次筛就得重读；二是它只返回 issue 名，没有关系与动作，
视图这边还得再按 id 回查快照。同一份快照里过滤是纯函数，切筛零延迟。

## 收集：放哪儿

- 页栏右侧本来就是"当前页的计数或工具"（`kiln-ui-refresh` 定的）：时间线放动作数、
  关系页放取景控件——**issue 页放筛选按钮**正好补上最后一格，不用新开一行。
- 展开的 chips 放在页栏下方、内容区之上：不随内容滚动，也不占常驻高度（默认收起）。
- chip 的"选中"直接用全站那一条（`bg-layer-2` + 600 字重 + 0.5px 内描边），不新增状态语言。
